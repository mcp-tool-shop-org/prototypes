# Security Policy

## Scope

This package is an ultra-thin launcher (12 lines) that delegates all functionality to `@mcptoolshop/npm-launcher`. It:

- Sets an environment variable with public repository metadata
- Requires the `@mcptoolshop/npm-launcher` module

**No user input is processed. No network requests are made. No files are read or written.**

## Reporting

To report a vulnerability, email 64996768+mcp-tool-shop@users.noreply.github.com or open a GitHub issue.
