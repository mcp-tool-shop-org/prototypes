Welcome to the Polyglot Handbook — your guide to translating text, files, and READMEs directly in VS Code using your local GPU.

## What is Polyglot?

Polyglot is a VS Code extension that runs TranslateGemma 12B through Ollama on your local GPU. It translates selected text, entire files, and README documentation into 55 languages — with zero cloud dependency, no API keys, and no data leaving your machine.
