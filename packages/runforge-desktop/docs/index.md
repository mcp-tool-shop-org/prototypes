# RunForge Desktop

Windows-native ML training run management with real-time charts and experiment control.

## Key Features

- **Training Configuration** — Epoch presets (Quick, Standard, Extended, Custom)
- **GPU/CPU Selection** — Automatic device detection
- **Hyperparameter Sweep** — Grid search with MultiRun
- **Live Monitoring** — Loss charts and log streaming
- **Artifact Inspection** — Browse metrics, logs, and outputs per run

## NuGet Package

```bash
dotnet add package RunForgeDesktop.Core
```
