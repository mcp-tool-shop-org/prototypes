# WebSketch MCP

MCP server exposing WebSketch IR tools for LLM agents.

## Key Features

- **MCP Protocol** — Standards-compliant Model Context Protocol server
- **WebSketch IR Tools** — Parse, validate, and transform UI intermediate representations
- **LLM-Ready** — Designed for AI agent consumption with structured tool schemas
- **TypeScript** — Fully typed with strict mode

## Install

```bash
npm install websketch-mcp
```
