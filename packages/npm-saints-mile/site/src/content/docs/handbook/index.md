Saint's Mile is a frontier JRPG for the adults who loved those games first. This handbook contains the complete design reference for building the game — from product thesis through implementation contracts.

## What This Handbook Contains

### Design Foundation
- [Product Thesis](/npm-saints-mile/handbook/product-thesis/) — what the game is, who it's for, what it must never become
- [Combat System](/npm-saints-mile/handbook/combat/) — party-based JRPG spine with frontier expression
- [The Party](/npm-saints-mile/handbook/party/) — six characters, six roles, six frontier truths

### The Campaign
- [Chapter Guide](/npm-saints-mile/handbook/chapters/) — 16 emotional laws across four life phases
- [Opening Arc](/npm-saints-mile/handbook/opening-arc/) — Prologue through Chapter 2: the sequence that proves the thesis

### Production
- [Build Constitution](/npm-saints-mile/handbook/build-constitution/) — anti-drift laws and runtime contracts
- [Implementation Guide](/npm-saints-mile/handbook/implementation/) — milestones, success tests, what to build first

### npm Wrapper
- [Getting Started](/npm-saints-mile/handbook/getting-started/) — install and play via npm with zero prerequisites
- [Reference](/npm-saints-mile/handbook/reference/) — CLI flags, platform support, versioning, and source repos
- [Beginner's Guide](/npm-saints-mile/handbook/beginners/) — first-time player walkthrough covering controls, saves, and early combat tips

## The Core Promise

A weathered frontier road story with sharp banter, real consequences, and just enough mystery to make the horizon feel haunted. Built for the generation that grew up on 90s classics.
