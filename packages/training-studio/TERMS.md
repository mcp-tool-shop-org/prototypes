## Description of Service

Training Studio is an open-source ML bundle validation tool that:
- Validates TensorFlow.js training bundle structure
- Verifies file integrity via SHA-256 hashes
- Provides JSON output for CI/CD integration
- Operates entirely offline on your local machine
