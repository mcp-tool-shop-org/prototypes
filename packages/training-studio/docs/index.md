# Training Studio

TensorFlow.js ML bundle validator with security-first design and zero code execution.

## Key Features

- **100% Local** — Train ML models in the browser, data never leaves your device
- **Zero Setup** — No Python, no cloud, just open and train
- **Security-First** — Bundle validation with no arbitrary code execution
- **Real-Time Feedback** — Live training charts and metrics
- **CSV Workflow** — Simple CSV-in, trained-model-out pipeline

## Install

```bash
npm install @mikeyfrilot/training-studio
```
