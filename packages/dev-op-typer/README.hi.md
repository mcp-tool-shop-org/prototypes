विंडोज के लिए एक डेवलपर-केंद्रित टाइपिंग अभ्यास ऐप — प्रत्येक परीक्षण वास्तविक कोड पर आधारित है।

> लिनक्स/मैकओएस के लिए भी उपलब्ध: [linux-dev-typer](https://github.com/mcp-tool-shop-org/linux-dev-typer) (एवलोनिया यूआई)

## विशेषताएं

### वास्तविक कोड अभ्यास
- **पायथन, जावास्क्रिप्ट, सी#, जावा, एसक्यूएल और बैश** में वास्तविक कोड स्निपेट टाइप करें।
- अक्षर-दर-अक्षर सटीकता ट्रैकिंग, जिसमें अंतर हाइलाइटिंग शामिल है।
- सटीक प्रतीक मिलान: `{ } [ ] ( ) < > ; : , . " ' \`
- नई लाइनें और इंडेंटेशन महत्वपूर्ण हैं।

### अनुकूलित शिक्षण
- आपके कौशल स्तर के आधार पर स्मार्ट स्निपेट चयन।
- प्रत्येक भाषा के लिए एलो-जैसे रेटिंग सिस्टम।
- सत्र योजनाकार: लक्ष्य (50%) / समीक्षा (30%) / विस्तार (20%) का मिश्रण।
- प्रति-अक्षर त्रुटि हीटमैप, जिसमें कमजोरियों के प्रक्षेपवक्र शामिल हैं।
- गाइडेड मोड: कमजोरियों पर आधारित चयन, जिसमें सूक्ष्म अभ्यास शामिल हैं।
- कठिनाई स्तर (डी1–डी7) जिसमें आराम क्षेत्र का पता लगाना शामिल है।

### लाइव आंकड़े
- वास्तविक समय में WPM (शब्द प्रति मिनट), सटीकता और त्रुटि गणना।
- सत्र पूर्णता, जिसमें पिछली जानकारी शामिल है।
- रुझान ट्रैकिंग: प्रति भाषा रोलिंग WPM और सटीकता।
- थकान का पता लगाना, जिसमें ब्रेक के सुझाव शामिल हैं।
- कमजोर बिंदुओं का पैनल, जिसमें अक्षर-स्तरीय विश्लेषण शामिल है।

### शिक्षण और समुदाय
- ढाँचे: प्रगतिशील संदर्भ संकेत, जिसमें "अधिक संदर्भ" परतें शामिल हैं।
- प्रदर्शन: वैकल्पिक कार्यान्वयन समान स्तर पर दिखाए जाते हैं।
- सामुदायिक संकेत: केवल प्रदर्शन के लिए युक्तियाँ और कठिनाई रेटिंग।
- साझा सामग्री पैकों से मार्गदर्शन नोट्स।
- संरचनात्मक समझ के लिए कौशल परत पैनल।

### सामग्री प्रणाली
- 6 भाषाओं में 168+ कैलिब्रेशन स्निपेट।
- उपयोगकर्ता स्निपेट पैक: JSON फ़ाइल को "पैक्स" फ़ोल्डर में डालें।
- कोड पेस्ट करें: क्लिपबोर्ड से किसी भी कोड को अभ्यास सामग्री के रूप में पेस्ट करें।
- फ़ाइल/फ़ोल्डर आयात करें: स्रोत फ़ाइलों को स्वचालित रूप से पता लगाए गए भाषा के साथ अनुक्रमित करें।
- सामग्री साझा करने के लिए `.ldtpack` बंडल निर्यात/आयात करें।
- सामग्री-आधारित आईडी (SHA-256 डुप्लिकेट)।

### ऑडियो
- कई थीम वाले एम्बिएंट साउंडस्केप।
- मैकेनिकल कीबोर्ड क्लिक ध्वनियाँ (5 थीम, प्रत्येक में 8 भिन्नताएं)।
- प्रति-चैनल वॉल्यूम नियंत्रण (एम्बिएंट, कीबोर्ड, यूआई)।
- शीर्षक बार से म्यूट/अनम्यूट।

### पहुंच क्षमता
- पूर्ण कीबोर्ड नेविगेशन।
- उच्च कंट्रास्ट थीम समर्थन।
- गति कम करने का विकल्प।
- सभी इंटरैक्टिव तत्वों पर ऑटोमेशन प्रॉपर्टीज।

### स्थायित्व
- प्रोफाइल जिसमें XP, स्तर और प्रति-भाषा रेटिंग शामिल हैं।
- सेटिंग्स और भाषा चयन सत्रों में सहेजा जाता है।
- सत्र इतिहास (500 रिकॉर्ड तक) जिसमें मासिक संपीड़न शामिल है।
- अभ्यास कॉन्फ़िगरेशन: इंजन ट्यूनिंग के लिए नामित पैरामीटर सेट।

## इंस्टॉल करें

### Microsoft Store (अनुशंसित)
जल्द ही उपलब्ध होगा — स्टोर प्रमाणन लंबित।

### स्रोत कोड से बनाएं

**आवश्यकताएं:**
- विंडोज 10 संस्करण 1809+ या विंडोज 11
- .NET 10.0 SDK
- विजुअल स्टूडियो 2022 (विंडोज ऐप SDK वर्कलोड के साथ) — या CLI

```bash
git clone https://github.com/mcp-tool-shop-org/dev-op-typer.git
cd dev-op-typer
dotnet build DevOpTyper/DevOpTyper.csproj -c Release -p:Platform=x64
```

बिल्ड किए गए निष्पादन योग्य फ़ाइल को चलाएं:
```
DevOpTyper\bin\x64\Release\net10.0-windows10.0.19041.0\DevOpTyper.exe
```

## अपना कोड जोड़ें

अपने स्वयं के कोड का अभ्यास करने के तीन तरीके हैं:

### विकल्प 1: कोड पेस्ट करें (सबसे आसान)

1. **सेटिंग्स** पैनल खोलें (शीर्ष बार में ⚙ पर क्लिक करें)
2. **पेस्ट कोड** पर स्क्रॉल करें
3. टेक्स्ट बॉक्स में कोई भी कोड स्निपेट पेस्ट करें
4. **जोड़ें** पर क्लिक करें — भाषा स्वचालित रूप से पता चल जाएगी
5. आपका कोड तुरंत स्निपेट रोटेशन में दिखाई देगा

### विकल्प 2: एक फ़ाइल या फ़ोल्डर आयात करें

1. **सेटिंग्स** खोलें → **इम्पोर्ट** तक स्क्रॉल करें।
2. एक सिंगल सोर्स फ़ाइल जोड़ने के लिए **इम्पोर्ट फ़ाइल** पर क्लिक करें, या पूरे प्रोजेक्ट को स्कैन करने के लिए **इम्पोर्ट फ़ोल्डर** पर क्लिक करें।
3. ऐप स्वचालित रूप से फ़ाइल एक्सटेंशन (`.py`, `.js`, `.cs`, `.java`, `.sql`, `.sh`) से भाषा का पता लगाता है।
4. इम्पोर्ट किया गया कोड कंटेंट हैश के माध्यम से डुप्लिकेट किया जाता है — एक ही कोड कभी भी दो बार नहीं जोड़ा जाता है।

### विकल्प 3: एक स्निपेट पैक (JSON) बनाएं।

अभ्यास के लिए तैयार किए गए स्निपेट के सेट के लिए:

1. अपने यूजर स्निपेट फ़ोल्डर को खोलें:
```
%LocalAppData%\DevOpTyper\UserSnippets\
```
(या सेटिंग्स में **स्निपेट फ़ोल्डर खोलें** पर क्लिक करें)।

2. भाषा के नाम से एक JSON फ़ाइल बनाएं (उदाहरण के लिए, `python.json`):
```json
{
"language": "python",
"snippets": [
{
"id": "my_list_comp",
"title": "लिस्ट कॉम्प्रिहेंशन",
"difficulty": 3,
"topics": ["लिस्ट", "कॉम्प्रिहेंशन"],
"code": "squares = [x**2 for x in range(10)]\n"
},
{
"id": "my_dict_comp",
"title": "डिक्शनरी कॉम्प्रिहेंशन",
"difficulty": 4,
"topics": ["डिक्ट", "कॉम्प्रिहेंशन"],
"code": "counts = {word: len(word) for word in words}\n"
}
]
}
```

3. ऐप को पुनः आरंभ करें — आपके स्निपेट अंतर्निहित स्निपेट के साथ दिखाई देंगे।

**सुझाव:**
- `id` सभी पैकों में अद्वितीय होना चाहिए।
- `difficulty` 1 (आसान) से 7 (कठिन) तक होता है।
- `code` `\n` के साथ समाप्त होना चाहिए।
- आप पैकों को एक स्तर गहरे सबडायरेक्टरी में व्यवस्थित कर सकते हैं।

### सामग्री साझा करना

अपने कस्टम स्निपेट को एक पोर्टेबल `.ldtpack` बंडल के रूप में एक्सपोर्ट करें:

1. **सेटिंग्स** खोलें → **बंडल एक्सपोर्ट करें** पर क्लिक करें।
2. `.ldtpack` फ़ाइल को दूसरों के साथ साझा करें।
3. वे इसे **सेटिंग्स** → **बंडल इम्पोर्ट करें** के माध्यम से इम्पोर्ट करते हैं।

केवल यूजर द्वारा बनाई गई सामग्री ही भेजी जाती है — कभी भी अभ्यास इतिहास या सेटिंग्स नहीं।
