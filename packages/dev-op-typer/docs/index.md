# Dev-Op-Typer

Developer-focused typing practice for Windows using real code snippets.

## Key Features

- **Real Code Practice** — Character-by-character accuracy with Python, JS, C#, Java, SQL, and Bash
- **Adaptive Learning** — Elo-like per-language rating with session planner (target/review/stretch)
- **Weakness Detection** — Per-character mistake heatmap across 10 symbol categories
- **Audio Feedback** — Mechanical keyboard click sounds and ambient soundscapes
- **Accessibility** — Full keyboard navigation and screen reader support
