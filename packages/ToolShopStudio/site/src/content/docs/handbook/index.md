ToolShopStudio bundles six MCP tools and a live registry into a single install. FFmpeg, Pandoc, FreeCAD, GDAL, OpenSCAD, and Blender — all wired for MCP with schema-first safety, sandboxed execution, and premium-to-guaranteed fallback.

## What's inside

- **FFmpeg YouTube MCP** — YouTube-safe transcoding with guaranteed + premium presets
- **Pandoc MCP** — Zero-flag document conversion (blog, academic PDF, ebook, slides, newsletter)
- **FreeCAD MCP** — Safe 3D CAD export (STL, STEP, GLB, 3MF, OBJ)
- **GDAL MCP** — Geospatial transforms (reproject, convert, clip)
- **OpenSCAD MCP** — Pure-text parametric CAD (text in, mesh out)
- **Blender MCP** — Headless 3D rendering (PNG, GLB, MP4, STL, Cycles)
- **Live Registry** — Query tools, presets, and output formats at runtime

## Shared contract

Every tool shares the same frozen surface: schema-first input validation, sandboxed file operations, observable progress notifications, context dependency injection, and zero raw CLI args.
