# venvkit

Python virtual environment diagnostic toolkit for Windows ML workflows.

## Key Features

- **doctorLite** — Fast health check for any Python interpreter (SSL, DLLs, ABI, pip)
- **scanEnvPaths** — Discover all Python environments on your system
- **mapRender** — Visualize your Python ecosystem (graph JSON, Mermaid, HTML)
- **runLog** — Track task execution history in append-only JSONL
- **taskCluster** — Detect flaky tasks and failure hotspots

## Install / Quick Start

```bash
npm install && npm run build
node dist/map_cli.js --root C:\projects --httpsProbe
```
