**विंडोज के लिए एन्वेलप बजटिंग - हर एक रुपये को एक काम दें।**

यह विंडोज के लिए एक व्यक्तिगत वित्त ऐप है जो एन्वेलप बजटिंग पद्धति का उपयोग करता है। आपका डेटा स्थानीय रूप से संग्रहीत होता है, इसके लिए क्लाउड की आवश्यकता नहीं है। यह एक **भविष्य के लेजर** के रूप में बनाया गया है - वित्तीय सत्य की एक आधिकारिक प्रणाली जिसमें हर सीमा पर स्पष्ट मानवीय नियंत्रण होता है।

## डाउनलोड

📦 **[नवीनतम रिलीज़](https://github.com/mcp-tool-shop-org/NextLedger/releases/latest)**

ZIP फ़ाइल डाउनलोड करें, उसे निकालें और `NextLedger.App.exe` चलाएं। इंस्टॉलेशन की आवश्यकता नहीं है।

## एन्वेलप बजटिंग क्या है?

एन्वेलप बजटिंग एक सरल, सिद्ध विधि है जिसमें आप अपनी आय को विभिन्न खर्चों की श्रेणियों के लिए वर्चुअल "एन्वेलप" में आवंटित करते हैं। आप केवल प्रत्येक एन्वेलप में मौजूद राशि ही खर्च कर सकते हैं, जिससे अत्यधिक खर्च करना असंभव हो जाता है।

## विशेषताएं

- **ऑफ़लाइन-फ़र्स्ट**: आपका डेटा आपके मशीन पर ही रहता है। इसके लिए क्लाउड की आवश्यकता नहीं है।
- **एन्वेलप बजटिंग**: हर एक रुपये को एक उद्देश्य के लिए आवंटित करें।
- **एकाधिक खाते**: बचत, चालू खाते, क्रेडिट कार्ड, नकदी को ट्रैक करें।
- **लेनदेन ट्रैकिंग**: अपने खर्चों को वर्गीकृत और खोजें।
- **CSV इम्पोर्ट**: बैंक स्टेटमेंट को आसानी से इम्पोर्ट करें।
- **मेल मिलाप (रिकंसिलिएशन)**: अपने रिकॉर्ड को बैंक स्टेटमेंट से मिलाएं।
- **विंडोज नेटिव**: आधुनिक विंडोज अनुभव के लिए WinUI 3 के साथ बनाया गया।

## विकास

### आवश्यकताएं

- विंडोज 10 (1809+) या विंडोज 11
- विजुअल स्टूडियो (2022 17.8+ या नया) जिसमें:
- .NET डेस्कटॉप डेवलपमेंट वर्कलोड
- विंडोज ऐप SDK C# टेम्पलेट्स
- विंडोज SDK / MSIX (ऐपक्स/PRI बिल्ड टूल्स)
- .NET 9 SDK

**CLI (कमांड लाइन इंटरफेस) बिल्ड (WinUI) पर ध्यान दें:** WinUI प्रोजेक्ट (`NextLedger.App`) विंडोज ऐप SDK बिल्ड चरणों को चलाता है, जिसके लिए Appx/MSIX + PRI MSBuild टास्क असेंबली की आवश्यकता होती है। यदि आपको `MSB4062` जैसी त्रुटि दिखाई देती है, जो `Microsoft.Build.AppxPackage.dll` या `Microsoft.Build.Packaging.Pri.Tasks.dll` जैसी गायब फ़ाइलों का उल्लेख करती है, तो विज़ुअल स्टूडियो इंस्टॉलर के माध्यम से विंडोज SDK / MSIX घटकों को स्थापित करें (या विज़ुअल स्टूडियो के भीतर से ऐप को बनाएं)।

### बिल्डिंग

```bash
dotnet restore
dotnet build
```

### ऐप को चलाने का तरीका

**विज़ुअल स्टूडियो (अनुशंसित)**

1. विज़ुअल स्टूडियो 2022 में `NextLedger.sln` फ़ाइल खोलें।
2. `NextLedger.App` को स्टार्टअप प्रोजेक्ट के रूप में सेट करें।
3. **F5** कुंजी दबाकर चलाएं।

**CLI (बिल्ड + लॉन्च)**

```bash
dotnet build .\src\NextLedger.App\NextLedger.App.csproj -c Debug
```

यदि यह `MSB4062` के साथ विफल हो जाता है, तो "आवश्यकताएं" अनुभाग में दिए गए नोट को देखें।

फिर बिल्ड आउटपुट फ़ोल्डर के अंतर्गत उत्पन्न exe फ़ाइल चलाएं:

- `.\src\NextLedger.App\bin\Debug\net9.0-windows10.0.19041.0\`

**स्थानीय डेटा का स्थान**

ऐप एक स्थानीय SQLite डेटाबेस बनाता है:

- `%LOCALAPPDATA%\NextLedger\NextLedger.db`
