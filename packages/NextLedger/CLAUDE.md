# NextLedger

## What This Does

Next-generation financial ledger and accounting system.
Provides ledger management, transaction tracking, and financial reporting.

## Core Features

- Transaction ledger management
- Multi-currency support
- Financial reporting and analytics
- Audit trail and compliance tracking
- Balance reconciliation

## Architecture

- Event-sourced ledger design
- CQRS (Command Query Responsibility Segregation) pattern
- RESTful API
- Real-time transaction processing

## Dependencies

- Python >= 3.11
- mcp >= 1.0.0
- SQLAlchemy (for ORM)
- Pydantic (for data validation)

## Key Notes

- Immutable transaction history
- Double-entry accounting principles
- Support for custom account hierarchies
- Automated reconciliation checks
