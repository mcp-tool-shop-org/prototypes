# NextLedger

Envelope budgeting for personal finance — offline-first, no cloud required.

## Key Features

- **Offline-First** — All data stored locally on your machine
- **Envelope Budgeting** — Allocate income to spending categories
- **Multiple Accounts** — Checking, savings, credit cards, cash
- **Transaction Tracking** — Categorization with CSV import
- **Reconciliation** — Match transactions against bank statements
- **Native Windows** — Built with WinUI 3
