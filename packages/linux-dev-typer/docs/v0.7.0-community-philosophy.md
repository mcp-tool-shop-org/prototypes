# v0.7.0 — Shared Craft, Quietly

## What Community Means Here

Community in Dev-Op-Typer means **shared knowledge through artifacts**, not shared identity through profiles.

Developers exchange `.ldtpack` files containing snippet packs, practice profiles, notes, and difficulty observations. That exchange happens outside the app — via email, file sharing, version control, USB drives, whatever works. The app has no server, no feed, no discovery mechanism.

When you import someone else's pack, their content becomes yours. There is no "external" label. There is no author badge. The content simply exists alongside everything else.

## What This Is NOT

- No user accounts or sign-in
- No social feeds, timelines, or notifications
- No followers, likes, or shares
- No leaderboards, rankings, or comparisons
- No attribution or reputation mechanics
- No discovery or recommendation algorithms
- No telemetry or usage tracking
- No centralized servers of any kind

## Design Principles

### 1. Solo Use Is First-Class
The app is complete without any shared content. Every feature works with zero imported packs, zero community notes, zero external signals. Sharing adds context; it never becomes required.

### 2. All Shared Content Is Optional
Both community-sourced features (Notes and CommunityDifficulty) can be toggled off independently from the sidebar. Disabling them has zero effect on practice behavior. No penalty, no nagging, no reminder to turn them back on.

### 3. Anonymous by Design
There is no author field on Notes. There is no source field on CommunityDifficulty. Content has no identity attached to it — not because we stripped it, but because it was never collected.

This is not privacy through policy. It is privacy through architecture.

### 4. Content Is Informational, Not Prescriptive
Notes use neutral language: "Some prefer...", "An alternative approach...", "In production you might...". Never "You should..." or "The correct way is...". Multiple perspectives coexist as equal entries. No single answer is endorsed.

### 5. Display-Only Signals
CommunityDifficulty appears as a number on the completion card. It never alters snippet selection, difficulty progression, rating calculation, or any engine behavior. The app's internal systems are completely isolated from community-sourced data.

## Format Changes

`.ldtpack` bundles use format version "2" (up from "1" in v0.6.0). Version 1 bundles still import correctly — missing fields default to null. Version 2 bundles include:

- `Notes` on snippets (optional `string[]?`)
- `CommunityDifficulty` on snippets (optional `double?`)

Both are omitted from exported JSON when null, keeping files clean for packs that don't use them.
