# Linux Dev Typer

Cross-platform code-only typing practice with adaptive learning, built with Avalonia UI.

## Key Features

- **Per-Character Feedback** — Elo-inspired per-language rating system
- **Adaptive Difficulty** — Comfort-zone detection with anti-yo-yo protection
- **168 Calibration Snippets** — Across 5 languages
- **Practice Intents** — Warmup, Drill, Explore, and Challenge modes
- **Guided Mode** — Weakness-biased selection with micro-drills

## NuGet Package

```bash
dotnet add package LinuxDevTyper.Core
```
