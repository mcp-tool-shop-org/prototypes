# Session Planner — v0.9.0

## Purpose

The session planner adds structured practice categories to snippet selection. Instead of always picking at or near the user's working level, it mixes three categories:

- **Target (50%)** — at the user's comfort zone, reinforcing current skills
- **Review (30%)** — one band below comfort, preventing skill decay
- **Stretch (20%)** — one band above comfort, gentle progression

## Design Principles

1. **Display-only** — SessionPlan never affects engine scoring, rating, or XP
2. **Transparent** — the plan reason is shown in the UI so the user understands why
3. **Deferential** — manual lock and yo-yo stabilization override the mix
4. **Bootstrapping** — before a comfort zone is established, all picks are Target
5. **Profile-aware** — comfort zone thresholds come from PracticeProfile parameters

## Algorithm

```
1. Manual lock? → Target at locked difficulty
2. Yo-yo detected? → Target at comfort zone (stabilize)
3. No comfort zone? → Target (rating-based, establishing baseline)
4. Comfort established → roll 50/30/20:
   - Target: comfort zone
   - Review: comfort - 1 (min 1)
   - Stretch: comfort + 1 (max 7)
5. Delegate to SnippetSelector.Pick() with target difficulty
```

## Integration

The planner wraps `SnippetSelector.Pick()`. It computes the mix category and target difficulty, then passes `suggestedDifficulty` to the existing selector. The selector still handles:

- Difficulty window widening by level
- Weakness profile boosting
- Focus category boosting
- Weighted random selection

## SessionPlan Record

```csharp
public sealed class SessionPlan
{
    public MixCategory Category { get; init; }    // Target, Review, or Stretch
    public int TargetDifficulty { get; init; }     // What we aimed for
    public int ActualDifficulty { get; init; }     // What was actually selected
    public int? ComfortZone { get; init; }         // User's current comfort
    public string Reason { get; init; }            // Human-readable explanation
}
```

## UI Display

- **Sidebar Difficulty section**: shows PlanReasonText below difficulty info
- **Top bar**: DifficultyInfoText includes category suffix ("review", "stretch")
- Both are subtle, muted — information without distraction
