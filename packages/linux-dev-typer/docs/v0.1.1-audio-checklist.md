# v0.1.1 Audio Integration Test Checklist

## Build

- [ ] `dotnet build` passes with 0 errors, 0 warnings
- [ ] `dotnet test` passes (22+ tests)
- [ ] Native `miniaudioex` library present in build output

## Keyboard SFX

- [ ] Typing produces key click sounds
- [ ] Rapid typing produces overlapping (polyphonic) sounds
- [ ] 5 themes visible in Keyboard Sound dropdown
- [ ] Selecting each theme changes key click sound immediately
- [ ] Key volume slider adjusts click loudness in real time

## Ambient Soundscapes

- [ ] Ambient track starts playing on app launch (if not muted)
- [ ] 4 soundscapes visible in Soundscape dropdown
- [ ] Selecting a soundscape changes ambient track
- [ ] Ambient volume slider adjusts loudness in real time
- [ ] Random button plays a different track within current soundscape
- [ ] Mute checkbox silences ambient without restarting track
- [ ] Unchecking Mute resumes from same position

## UI Sounds

- [ ] Clicking "Next" on completion card plays UI click
- [ ] UI volume slider adjusts click loudness

## Accessibility

- [ ] Enabling Reduced Sensory caps all volumes at 0.3
- [ ] Disabling Reduced Sensory restores original volumes

## Persistence

- [ ] Close and reopen app: all audio settings preserved
- [ ] Keyboard theme selection persisted
- [ ] Soundscape selection persisted
- [ ] Volume levels persisted
- [ ] Mute state persisted
- [ ] Delete `state.json`: app starts with defaults, no crash

## Fallback

- [ ] If native audio library is missing: app starts with no audio, no crash
- [ ] All typing and progression features work without audio
