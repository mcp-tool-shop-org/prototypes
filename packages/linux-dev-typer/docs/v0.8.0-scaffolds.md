# Scaffolds

## What Scaffold Is

A **Scaffold** is an optional progressive learning context attached to a snippet. It provides layered depth: a shallow hint at index 0, and progressively deeper context at index 1+. The user controls how deep they go.

Scaffolds describe patterns. They never prescribe behavior.

## Structure

```json
{
  "scaffold": [
    "This uses a list comprehension with a range.",
    "List comprehensions evolved from set-builder notation in mathematics.",
    "Python's comprehension syntax was inspired by Haskell's list monad."
  ]
}
```

- **Index 0**: Shallow hint. Visible by default (behind the Details toggle).
- **Index 1+**: Deeper context. Behind a "More context" button.
- **null**: No scaffold. The snippet works identically without one.

## Authoring Guide

### Language

Use observational language:
- "This pattern uses..." (describes what's there)
- "The syntax originates from..." (provides history)
- "An alternative structure appears in..." (points outward)

Never prescriptive:
- ~~"You should use..."~~
- ~~"The correct approach is..."~~
- ~~"Beginners should start with..."~~

### Depth Progression

Layer 0 should orient. Layer 1+ should deepen. Each layer stands alone.

A reader who stops at layer 0 got something useful. A reader who goes deeper got more. Neither is "wrong" for stopping where they did.

### Keep It Brief

Each layer is a sentence or two. Scaffolds are observations, not tutorials.

## What Scaffold Is NOT

- **Not a tutorial.** Scaffolds don't teach step-by-step.
- **Not a prerequisite chain.** Layer 2 doesn't require layer 1.
- **Not a difficulty indicator.** A 3-layer scaffold doesn't mean "hard."
- **Not a curriculum.** There's no sequence between scaffolds on different snippets.
- **Not a grade.** The app never records whether a user read scaffolds.

## Display Behavior

1. Scaffold appears on the completion card, behind the existing Details toggle.
2. Layer 0 shows as an accent-colored hint with `^` prefix.
3. If deeper layers exist, a "More context" button appears.
4. Clicking "More context" reveals layers 1+ in muted color with `^` prefix.
5. The `ShowScaffolds` toggle in the sidebar hides the entire section.
6. The app never tracks scaffold interaction.

## Engine Isolation

Scaffolds are display-only. They never affect:
- Snippet selection or weighting
- Difficulty calculation or adjustment
- Rating computation
- XP calculation
- Any engine behavior whatsoever

This is enforced by reflection tests in `ProfileInvariantTests.cs`.
