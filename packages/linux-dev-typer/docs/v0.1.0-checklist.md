# v0.1.0 Verification Checklist

## Build & Run
- [ ] `dotnet restore` completes without errors
- [ ] `dotnet build -c Release` succeeds (0 warnings, 0 errors)
- [ ] `dotnet test` passes all tests (22+)
- [ ] `dotnet run --project src/LinuxDevTyper.App/LinuxDevTyper.App.csproj` opens the app window

## Core Typing
- [ ] "New Test" loads a snippet with title and code
- [ ] Typing updates WPM, accuracy, and error count in real-time
- [ ] Per-character feedback: correct chars teal, wrong chars red+underline, untyped muted
- [ ] Exact match completes the session
- [ ] Completion card shows WPM, accuracy, errors, XP earned
- [ ] "What you learned" bullets display snippet explanations
- [ ] "Next" button advances to a new snippet
- [ ] "Reset" clears typed text and restarts the session

## Progression
- [ ] XP awarded on completion
- [ ] Level badge updates when XP threshold reached
- [ ] Per-language rating adjusts after each session
- [ ] Higher levels widen the difficulty window upward

## Persistence
- [ ] `~/.config/linux-dev-typer/state.json` is created on first save
- [ ] Profile (level, XP, ratings) persists across restarts
- [ ] Settings (language, font size, sidebar state) persist across restarts
- [ ] Recent results (last 50) persist across restarts
- [ ] Last 5 results display in stats panel
- [ ] Schema migration handles v1 state files without crashing

## Language Discovery
- [ ] Language dropdown populated from `assets/snippets/*.json`
- [ ] Switching languages loads correct snippets
- [ ] Missing/corrupt snippet files handled gracefully (no crash)

## Settings
- [ ] Sidebar toggles open/closed via gear button
- [ ] Font size slider affects both prompt and input
- [ ] Reduced sensory checkbox persists
- [ ] Settings saved on change

## Accessibility
- [ ] Typing box auto-focused on startup, New Test, Reset, sidebar close
- [ ] Focus outlines visible on buttons, textbox, combobox, checkbox, slider
- [ ] Font size configurable (12-24)
- [ ] All controls keyboard-reachable

## Audio (Stub)
- [ ] IAudioService interface defined in Core
- [ ] StubAudioService wired (no-op, no crashes)
- [ ] Volume settings persist but have no audible effect (expected for v0.1.0)

## CI
- [ ] `.github/workflows/build.yml` runs restore, build, test on ubuntu-latest
