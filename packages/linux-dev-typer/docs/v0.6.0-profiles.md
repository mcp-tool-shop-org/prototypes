# Practice Profile Reference

Practice profiles let you tune engine behavior without modifying code. Each profile is a named set of constants that the engines use instead of their defaults.

## Using Profiles

1. Open the sidebar (gear icon)
2. Under **Practice Profiles**, click "Create" to make a new profile
3. Adjust sliders to tune parameters
4. The profile is active immediately; switch back to "Default" any time

The "Default" profile cannot be edited or deleted. It always matches the hardcoded engine constants.

## Parameter Reference

### XP Tuning

| Parameter | Default | Range | Description |
|-----------|---------|-------|-------------|
| XP Multiplier | 0.8 | 0.1-2.0 | Base multiplier for (WPM x accuracy%) in XP calculation |
| Repeat Decay | 0.3 | 0.0-1.0 | How fast XP diminishes for repeated snippets |
| Sloppy Threshold | 70% | 50-95% | Accuracy below this triggers the sloppy penalty |
| Sloppy Penalty | 0.5 | 0.0-1.0 | XP multiplier when accuracy is below threshold |
| Completion Bonus | 25 | 0-100 | Base XP bonus for finishing a snippet |

### Rating Tuning

| Parameter | Default | Range | Description |
|-----------|---------|-------|-------------|
| K-Factor | 32 | 8-64 | Maximum rating shift per session (Elo-style) |
| Difficulty Base | 400 | 100-1000 | Base opponent rating in Elo formula |
| Difficulty Scale | 200 | 50-500 | Per-difficulty multiplier for opponent rating |

### Difficulty Tuning

| Parameter | Default | Range | Description |
|-----------|---------|-------|-------------|
| Comfort Accuracy | 85% | 60-98% | Minimum avg accuracy to establish a comfort zone |
| Comfort Min Sessions | 3 | 1-10 | Sessions needed at a difficulty to establish comfort |
| Yo-Yo Window | 6 | 3-20 | Recent sessions checked for yo-yo detection |
| Yo-Yo Swing | 20% | 5-50% | Accuracy swing threshold for yo-yo detection |

### Trend Tuning

| Parameter | Default | Range | Description |
|-----------|---------|-------|-------------|
| WPM Threshold | 2.0 | 0.5-10.0 | WPM delta required to classify a non-Stable trend |
| Accuracy Threshold | 1.0 | 0.5-5.0 | Accuracy delta required for non-Stable trend |
| Min Sessions | 5 | 3-20 | Sessions needed before reporting trends |

### Fatigue Tuning

| Parameter | Default | Range | Description |
|-----------|---------|-------|-------------|
| Break Sessions | 5 | 3-20 | Suggest break after this many sessions |
| Accuracy Drop | 3.0% | 1-15% | Suggest break if accuracy drops this much |

## Safety

All values are clamped to safe ranges when loaded. Extreme values cannot crash engines or produce invalid results (XP is always non-negative, rating always >= 100, difficulty always 1-7).

## Portability

Profiles are included in `.ldtpack` exports. When imported on another machine, profiles merge without overwriting existing ones.
