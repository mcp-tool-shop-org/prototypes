# v1.0.0 Guided Mode — Manual Validation Checklist

## Pre-Conditions

- Build: `dotnet build -c Release` succeeds with 0 warnings
- Tests: `dotnet test` passes 790+ tests
- App launches without errors

## 1. Default State (Fresh Install)

| Step | Expected |
|------|----------|
| Launch app | Guided Mode checkbox unchecked in sidebar |
| Open sidebar -> Guided Mode section | "Enable guided practice" unchecked |
| Below checkbox: description text visible | "Prefers snippets matching your weak spots" |
| Below description: policy note | "Off = v0.9 behavior (no signal influence)" |
| Complete 5 typing sessions | Behavior identical to v0.9 (no signal influence) |

## 2. Enabling Guided Mode

| Step | Expected |
|------|----------|
| Check "Enable guided practice" | Checkbox becomes checked |
| Close and reopen app | Checkbox remains checked (persisted) |
| Complete typing session | Snippet selection may prefer weak-spot snippets |
| Difficulty band unchanged | Same D-level candidates as without Guided Mode |

## 3. Disabling Guided Mode

| Step | Expected |
|------|----------|
| Uncheck "Enable guided practice" | Checkbox becomes unchecked |
| Close and reopen app | Checkbox remains unchecked (persisted) |
| Complete typing session | Selection reverts to v0.9 behavior |

## 4. Micro-Drill

| Step | Expected |
|------|----------|
| Build weakness data (complete 10+ sessions with typos) | "Weak spots" panel shows data |
| Click "Micro-drill" button | Focus mode activates, drill counter shows "Item 1 of 5" |
| Complete snippet | Counter advances to "Item 2 of 5" |
| Complete 5 snippets total | Drill mode auto-exits, focus mode clears |
| Click "Clear Focus" during drill | Both drill and focus mode exit |

## 5. Sidebar Tab Order

| Step | Expected |
|------|----------|
| Tab through sidebar elements | Order: ... -> Teaching -> **Guided Mode** -> Practice Profiles -> ... |
| Guided Mode checkbox focusable | Can toggle with Space/Enter |
| Micro-drill button focusable | Can activate with Enter |

## 6. No Signal Leakage

| Step | Expected |
|------|----------|
| Guided Mode OFF, play 20 sessions | Rating, XP, difficulty progression normal |
| Guided Mode ON, play 20 sessions | Rating, XP, difficulty progression unchanged from OFF |
| Check state.json | SignalPolicy present with expected flags |

## 7. Migration

| Step | Expected |
|------|----------|
| Copy v0.9 state.json | App loads, migrates to schema v12 |
| Guided Mode defaults to OFF | No unexpected behavior change |
| All existing data preserved | XP, rating, heatmap, snapshots intact |

## 8. Edge Cases

| Step | Expected |
|------|----------|
| Enable Guided Mode with no weakness data | App functions normally, no bias applied |
| Enable Guided Mode with empty heatmap | No errors, selection proceeds normally |
| Micro-drill with no weakness data | Button click does nothing (no crash) |
| Very large heatmap (200+ chars) | Prune runs on snapshot, stays bounded |
