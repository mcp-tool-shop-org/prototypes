# Difficulty Derivation — v0.8.2

## Overview

v0.8.2 replaces the hardcoded `Difficulty=3` default with a deterministic, metrics-based derivation. Every CodeItem that enters the pipeline without authored difficulty metadata receives a tier computed from its CodeMetrics.

## Design Constraints

- **No ML.** No models, no training data, no adaptation.
- **No user input.** Difficulty is never inferred from typing performance.
- **Deterministic.** Same code always produces the same tier.
- **Reproducible.** The algorithm is documented; anyone can predict the result.
- **Override-safe.** Authored difficulty in sidecar metadata always wins.

## Algorithm

Three bands, each scoring 0-3 points:

### Line Count Band

| Lines | Score |
|-------|-------|
| 1-5   | 0     |
| 6-15  | 1     |
| 16-30 | 2     |
| 31+   | 3     |

### Symbol Density Band

Symbol density = (symbol characters) / (non-whitespace characters).

| Density   | Score |
|-----------|-------|
| < 0.15    | 0     |
| 0.15-0.30 | 1     |
| 0.30-0.45 | 2     |
| > 0.45    | 3     |

### Max Indent Depth Band

Indent depth = leading whitespace / 4 (tabs count as 4 spaces).

| Depth | Score |
|-------|-------|
| 0-1   | 0     |
| 2     | 1     |
| 3     | 2     |
| 4+    | 3     |

### Mapping to Difficulty

Total score ranges 0-9. Mapped to difficulty 1-7:

```
difficulty = clamp(1 + score * 6 / 9, 1, 7)
```

| Score | Difficulty |
|-------|------------|
| 0     | 1          |
| 1     | 1          |
| 2     | 2          |
| 3     | 3          |
| 4     | 3          |
| 5     | 4          |
| 6     | 5          |
| 7     | 5          |
| 8     | 6          |
| 9     | 7          |

## Precedence

1. **Sidecar metadata** (authored difficulty from built-in packs or user packs) always wins.
2. **Derived difficulty** applies to content without sidecar metadata: pasted code, imported files/folders, and any CodeItem that enters through `ContentIntegrationService.CodeItemToSnippet()`.

## Invariants

- `DifficultyDeriver.FromMetrics()` never returns outside 1-7.
- Same `CodeMetrics` always produces the same difficulty.
- The derivation never reads user performance data, ratings, or profiles.
- The derivation never reads snippet metadata (Topics, Explain, Notes, etc.).

## Implementation

- `DifficultyDeriver.cs` — static class with `FromMetrics(CodeMetrics)` method.
- `ContentIntegrationService.CodeItemToSnippet()` — calls `DifficultyDeriver.FromMetrics(item.Metrics)`.
- `ContentPipeline.ApplyMetadata()` — uses sidecar difficulty, overriding the derived value.
