# Creating Snippet Packs

User-authored snippet packs use the same JSON format as built-in packs and are loaded automatically at startup.

## Quick Start

1. Create a JSON file named `{language}.json` (e.g., `go.json`, `typescript.json`)
2. Place it in the packs directory:
   - **Linux/macOS:** `~/.config/linux-dev-typer/packs/`
   - **Windows:** `%APPDATA%/linux-dev-typer/packs/`
3. Restart the app or click **Refresh Packs** in the sidebar

## Format

Each file is a JSON array of snippet objects:

```json
[
  {
    "id": "go-hello-001",
    "language": "go",
    "difficulty": 2,
    "title": "Hello World",
    "code": "package main\n\nimport \"fmt\"\n\nfunc main() {\n\tfmt.Println(\"Hello, world!\")\n}\n",
    "topics": ["basics", "fmt"],
    "explain": ["Every Go program starts with a package declaration.", "The fmt package provides formatted I/O."]
  }
]
```

## Field Reference

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `id` | string | yes | Unique identifier within the pack |
| `language` | string | yes | Language name (should match filename) |
| `difficulty` | int | yes | 1 (easiest) to 7 (hardest) |
| `title` | string | no | Display name for the snippet |
| `code` | string | yes | The code to type (use `\n` for newlines, `\t` for tabs) |
| `topics` | string[] | no | Tags for categorization |
| `explain` | string[] | no | Bullet points shown after completion |

## Validation Rules

The pack validator checks:
- Every snippet has a non-empty `id`, `code`, and `language`
- Difficulty is between 1 and 7
- No duplicate IDs within a pack

Invalid snippets are skipped. Other snippets in the same pack still load.

## Tips

- **End code with `\n`** for clean display
- **Use LF newlines** (not CRLF) inside the `code` field
- **Keep snippets focused** (10-30 lines is the sweet spot for practice)
- **Vary difficulty** within a pack so the adaptive system can match player skill
- **Test your pack** by dropping it in and playing a few snippets

## Managing Packs

In the sidebar under **Snippet Packs**:
- Enable/disable individual packs with checkboxes
- Click **Refresh Packs** after adding or modifying files
- Pack state persists across sessions

User packs merge with built-in packs. If both provide the same language, snippets are combined.
