# v0.7.0 — Sharing Without Social Signaling

## How Sharing Works

Developers exchange `.ldtpack` files containing snippet packs, practice profiles, and optionally Notes and CommunityDifficulty observations. That exchange happens **outside the app** — email, file sharing, version control, USB drives, whatever works.

The app has no server, no feed, no discovery mechanism.

## What Travels

| Content | Included | Format |
|---------|----------|--------|
| Snippet packs | Yes | Array of snippets per language |
| Practice profiles | Yes | Named parameter sets (excluding "Default") |
| Notes on snippets | Yes (v2) | `string[]?` — tips, alternatives, perspectives |
| CommunityDifficulty | Yes (v2) | `double?` — difficulty observation from others |

## What Never Travels

- Practice history or session results
- Mistake profiles or weakness data
- Personalization preferences
- State.json or any persisted state
- Identity, author names, or source metadata

## Format Versions

**v1** (0.6.0): Packs and profiles only.
**v2** (0.7.0): Adds optional Notes and CommunityDifficulty on snippets.

v1 bundles import into v0.7.0 cleanly — missing fields default to null. v2 bundles use `DefaultIgnoreCondition.WhenWritingNull` so null fields are omitted from exports, keeping files clean.

## Anonymous by Design

There is no author field on Notes. There is no source field on CommunityDifficulty. When you import someone else's pack, their content becomes yours — indistinguishable from locally created content. This is not privacy through policy; it is privacy through architecture.

- No `Source` property on Snippet
- No `Author` property on Snippet
- No `Origin` property on Snippet
- No `ImportedFrom` property on Snippet

Reflection tests enforce this constraint.

## No Attribution Pressure

Notes use neutral language that coexists without endorsement:
- "Some prefer..."
- "An alternative approach..."
- "In production you might..."

Never: "You should..." or "The correct way is..."

Multiple perspectives live side by side as equal entries. No single answer is endorsed.
