# v1.0.0 Release Notes

## What's New

### Guided Mode (Opt-In)

Guided Mode is a single toggle that allows your typing weakness data to influence snippet selection. When enabled, the system prefers snippets that exercise characters and symbol categories you struggle with — within the same difficulty band.

- **Default: OFF** — v0.9 behavior is preserved unless you opt in
- **When ON**: snippet selection applies bounded bias (+0 to +3 weight) toward snippets containing your weak characters and categories
- **Never changes**: difficulty band, rating, XP, or difficulty progression

### Micro-Drills

Quick 5-item focused practice sessions targeting your top weakness category. Click "Micro-drill" in the sidebar to start. The drill auto-exits after 5 completions.

### Signal Storage Hygiene

Heatmap data is now bounded:
- Maximum 200 tracked characters (pruned by attempt count)
- Maximum 20 confusion pairs per character (pruned by frequency)
- Maximum 90 weakness snapshots (rolling window)
- Pruning is deterministic and runs on daily snapshot

### Library Health Diagnostics

The Library sidebar section now shows a health summary: total snippets, language count, source breakdown, heatmap character count, and snapshot count.

## Architecture

### SignalPolicy

Feature-flag object controlling signal influence:
- `GuidedMode`: master switch (default: false)
- `SignalsAffectSelection`: selection bias (default: false)
- `SignalsAffectDifficulty`: reserved, always false
- `SignalsAffectXP`: reserved, always false
- `Effective*` properties require both master + sub-flag

### Bias System

Two additive biases in SnippetSelector, gated by `EffectiveSelectionBias`:
1. **HeatmapBias**: per-character weakness (+1 per weak char, cap +3)
2. **HeatmapCategoryBias**: per-category weakness (+1 per category, cap +3, requires 2+ weak categories)

### Schema v12

Migration from any prior schema (v1-v11) preserves all data. New fields default safely:
- `AppSettings.SignalPolicy` defaults to all-off
- No user preference is changed during migration
