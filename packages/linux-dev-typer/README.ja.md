**開発者向けのコーディング練習ツール — Avalonia UI を採用、難易度調整機能、傾向追跡機能、疲労検知機能。**

> ネイティブWindowsアプリとしても利用可能: [dev-op-typer](https://github.com/mcp-tool-shop-org/dev-op-typer) (WinUI 3, Microsoft Store)

---

## Linux Dev Typer を選ぶ理由

- **実践的なコードで練習。** あいまいな文章ではなく、Python、Rust、JavaScript、C#、またはJavaの実際のコードパターンを使用します。
- **適応的な難易度。** Eloレーティングにインスパイアされたシステムが、言語ごとにあなたのスキルレベルを調整します。また、スキルが停滞したり、逆に低下したりするのを防ぐ機能と、快適ゾーンからの脱却を促す機能も搭載しています。
- **弱点に合わせた練習。** 文字ごとの間違いをヒートマップで表示し、どの部分に苦戦しているかを把握し、弱点克服に特化した練習を促します。
- **疲労検知機能。** パフォーマンスの低下を検知し、悪い習慣が身につく前に休憩を促します。
- **クロスプラットフォーム。** Avalonia UI を採用しており、Linux、macOS、Windows で同じコードベースから動作します。
- **完全にオフライン。** テレメトリー機能はなく、アカウント登録も不要で、ネットワーク接続も必要ありません。あなたの入力データはすべてローカルマシンに保存されます。
- **拡張性。** コアエンジンは、UI依存性ゼロのスタンドアロンNuGetパッケージとして提供されます。

## 機能

### コアコーディングエンジン
- 文字ごとのフィードバック: 正しい (ティールグリーン)、エラー (赤色 + 下線)、未入力 (グレー)
- リアルタイムの統計: WPM (1分あたりの入力文字数)、正確性、エラー数、XP (経験値)
- Eloレーティングにインスパイアされた、言語ごとのレーティングシステム
- XPと難易度の段階的なレベルアップ
- コードスニペットの説明付きの完了カード
- 設定可能: フォントサイズ、空白ルール、改行コードの正規化

### 適応学習
- 文字ごとの間違い追跡機能 (10種類の記号分類)
- セッションごとの弱点プロファイリングと、適応的なコードスニペットの選択
- 傾向追跡: 言語ごとのWPMと正確性の推移
- 快適ゾーンの検知と、スキル停滞を防ぐ機能による適応的な難易度調整
- セッション後の分析: 過去最高記録、目標達成、傾向のサイン
- 疲労検知機能と、休憩の提案
- ハードコアモード: 間違いをすべて修正してから次のステップに進む

### 学習と振り返り
- 練習の目的選択機能: セッションを「ウォームアップ」「ドリル」「探索」「チャレンジ」としてタグ付け
- セッションノートと、検索/フィルタ機能付きのセッションブラウザ
- 再び利用した際のウェルカムメッセージと、自動的な難易度調整
- システムの提案のオーバーライド: スキル停滞を防ぐ機能、分析の種類、疲労アラートの抑制
- 200セッションを超える場合の月ごとの履歴圧縮
- 事前セッションの提案: コンテンツに基づいた、控えめなアドバイス
- スキル停滞の検知と、励ましのメッセージ
- パーソナライズ設定: 学習の一時停止、設定のリセット

### コンテンツシステム
- ユーザー定義のコードスニペットパック: JSONファイルを `~/.config/linux-dev-typer/packs/` に配置
- 練習プロファイル: エンジンの動作を調整する、名前付きのパラメータセット
- コンテンツ共有用の `.ldtpack` バンドルのインポート/エクスポート
- コードのペースト、ファイルのインポート、フォルダのインポート (自動言語検出)
- コンテンツアドレス指定ID (SHA-256による重複排除)
- 統一されたパイプライン: すべてのコンテンツが、メトリクスに基づいた難易度 (D1–D7) を持つ `CodeItem` として取り込まれる

### 教育とコミュニティ
- スキャフォールド：段階的な学習環境で、必要に応じてより詳細な機能を追加可能。
- バリアント：代替の実装方法を、同等のものとして表示。
- コミュニティノート：`.ldtpack`ファイルに、オプションで役立つヒントや視点を提供。
- コミュニティによる難易度：クラウドソーシングによる難易度を示す、表示専用のインジケーター。
- 設計上、匿名化：インポートされたコンテンツは、ローカルのコンテンツと区別できません。
- すべての学習機能とコミュニティ機能はオプションであり、表示専用です。

### 実践練習
- 168個のキャリブレーションサンプル（D1～D7の範囲をカバー）
- セッションプランナー：目標（50%）/ レビュー（30%）/ 強化（20%）の組み合わせ
- 時間経過とともに減衰するウィンドウを使用した、弱点検出
- 選択理由の透明性：「このサンプルを選んだ理由」で、すべての選択理由を説明
- 文字ごとのヒートマップと、混同しやすい文字のペア表示
- 弱点トラジェクトリー：日ごとのスナップショットで、進捗状況を追跡

### ガイド付き練習
- ガイドモード：オン/オフの切り替えで、弱点を示すインジケーターが選択に影響を与えるように設定可能。
- 弱点バイアス：カテゴリレベルでのバイアス（+0～+3の範囲。難易度バンドは変更されません）。
- マイクロドリル：上位の弱点に対処するための、5つの項目からなる集中練習セッション。
- シグナルポリシー：機能フラグのアーキテクチャで、マスタースイッチと、各機能ごとのサブフラグを設定可能。
- ストレージの最適化：ヒートマップは最大200文字、混同しやすい文字のペアは最大20個、スナップショットは最大90個まで。
- デフォルトはオフ：明示的にオンにしない限り、以前の動作が維持されます。

### オーディオ
- 5種類のキーボードサウンドテーマ（各8種類のバリエーション）
- 4種類の環境音（合計15トラック）
- 各チャンネルの音量調整とミュート機能

### アクセシビリティ
- キーボード操作に最適化されたUIで、フォーカスが明確に表示されます。
- 感覚過敏モード（音量を抑制）
- 高コントラストダークテーマ

## クイックスタート

**必要条件:** [.NET SDK 8.x](https://dotnet.microsoft.com/download/dotnet/8.0)

```bash
git clone https://github.com/mcp-tool-shop-org/linux-dev-typer.git
cd linux-dev-typer
dotnet restore
dotnet build -c Release
dotnet run --project src/LinuxDevTyper.App/LinuxDevTyper.App.csproj
```

## 独自のコードの追加

独自のコードを練習する方法は3つあります。

### オプション1：コードの貼り付け（最も簡単）

1. サイドバーを開きます（歯車のアイコンをクリック）。
2. **コードの貼り付け**セクションを見つけます。
3. テキストボックスに任意のコードスニペットを貼り付けます。
4. **追加**をクリックします。言語は自動的に検出されます。
5. コードはすぐにスニペットのリストに追加されます。

### オプション2：ファイルまたはフォルダのインポート

1. サイドバーを開き、**インポート**を見つけます。
2. **ファイルのインポート**をクリックして、単一のソースファイルをインポートするか、**フォルダのインポート**をクリックして、プロジェクト全体をスキャンします。
3. アプリは、ファイル拡張子（`.py`、`.rs`、`.js`、`.cs`、`.java`、`.sh`）から言語を自動的に検出します。
4. インポートされたコードは、コンテンツハッシュによって重複排除されます。同じコードは二度と追加されません。

### オプション3：スニペットパック（JSON）の作成

練習用のコードスニペットのセットを作成する場合：

1. 以下のフォルダにJSONファイルを作成します。
```
~/.config/linux-dev-typer/packs/
```

2. ファイル名を言語名にすると便利です（例：`python.json`）。
```json
{
"language": "python",
"snippets": [
{
"id": "my_list_comp",
"title": "リスト内包表記",
"difficulty": 3,
"topics": ["リスト", "内包表記"],
"code": "squares = [x**2 for x in range(10)]\n"
},
{
"id": "my_dict_comp",
"title": "辞書内包表記",
"difficulty": 4,
"topics": ["辞書", "内包表記"],
"code": "counts = {word: len(word) for word in words}\n"
}
]
}
```

3. アプリケーションを再起動します。追加したスニペットは、組み込みのスニペットとマージされ、サイドバーから有効/無効を切り替えることができます。

**ヒント:**
- `id` は、すべてのパッケージ全体で一意である必要があります。
- `difficulty` は、1（簡単）から7（難しい）の範囲です。
- `code` は、最後に `\n` を含めるようにしてください。
- ユーザーが作成したパッケージは、ファイルを削除せずに有効/無効を切り替えることができます。

### コンテンツの共有

カスタムスニペットを、持ち運び可能な `.ldtpack` ファイルとしてエクスポートします。

1. サイドバーを開き、**エクスポート** をクリックします。
2. `.ldtpack` ファイルを他のユーザーと共有します。
3. 相手は、サイドバーから **インポート** を選択してインポートします。

ユーザーが作成したコンテンツのみが共有されます。履歴や設定は共有されません。
