Linux Dev Typer is an offline, cross-platform code-typing trainer built on Avalonia UI.
It tracks your weaknesses, adapts difficulty, and helps you build muscle memory for real programming patterns.

- **[Guided Practice](/linux-dev-typer/handbook/guided-practice/)** — Session planner, guided mode, micro-drills, selection transparency, and plateau detection.
