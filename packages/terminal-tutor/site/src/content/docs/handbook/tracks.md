Terminal Tutor organizes lessons into skill tracks. Each track is a progression — lessons build skills, games test them.

## Shell Fundamentals

The foundation. Navigate filesystems, search text, process data, and edit files from the command line.

| Order | Scenario | Mode | Skills |
|-------|----------|------|--------|
| 1 | Files & Navigation | lesson | ls, cat, grep, find |
| 2 | Pipes & Search | lesson | grep -r, sort, uniq, wc, pipes |
| 3 | File Surgery | lesson | sed, awk, diff, in-place edits |
| 4 | Filesystem Salvage | game | Evidence trails, file recovery, data assembly |

**After this track:** You can explore any codebase, search for patterns, edit config files, and chain commands.

## Shell Triage

Investigate problems when something goes wrong.

| Order | Scenario | Mode | Skills |
|-------|----------|------|--------|
| 1 | Process Basics | lesson | ps, jobs, grep -B, log analysis |

**After this track:** You can find what's running, read logs, and trace failures.

## Git Survival

The git commands you actually need, practiced on a real repo.

| Order | Scenario | Mode | Skills |
|-------|----------|------|--------|
| 1 | Git Basics | lesson | init, status, add, commit, branch, checkout |

**After this track:** You can start repos, commit safely, and branch without fear.

## Python Debugging

Find and fix real bugs with real tools.

| Order | Scenario | Mode | Skills |
|-------|----------|------|--------|
| 1 | Python Debugging | lesson | pytest, tracebacks, import fixes |
| 2 | Dependency Detective | lesson | pip, requirements.txt, ModuleNotFoundError |
| 3 | Dependency Lab | game | Pipeline repair, test-driven debugging |

**Requires:** Python 3.10+ with venv support.

**After this track:** You can diagnose import errors, fix failing tests, and manage Python dependencies.

## Service Debugging

Triage a failing service stack.

| Order | Scenario | Mode | Skills |
|-------|----------|------|--------|
| 1 | Service Triage | lesson | Logs, processes, config, health endpoints |
| 2 | Service Siege | game | Cascading failure diagnosis, incident reporting |

**Requires:** Docker.

**After this track:** You can trace cascading failures, read service logs, diff configs, and write incident reports.

## Track Progression

Each track follows the pattern: **learn** (guided lessons) then **play** (replayable game).

Lessons have step-by-step guidance with hints. Games have win conditions and scoring but less hand-holding. If you can beat the game without hints, you've mastered the skills.
