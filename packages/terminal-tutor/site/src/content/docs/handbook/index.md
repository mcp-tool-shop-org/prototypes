Terminal Tutor is a situated coaching system that teaches terminal skills through real command execution. You learn by doing, not by reading.

## The Thesis

Most terminal training fails because it happens in the wrong place — browser tabs, sandbox environments, video players. Terminal Tutor works because the teaching happens *inside the terminal*, with real commands producing real outcomes on real files.

## What You Get

- **11 scenarios** (8 lessons + 3 games) across shell, Python, and Docker
- **5 skill tracks** that build from fundamentals to triage
- **3 runtimes** with honest capability boundaries
- **Mastery signals** based on actual performance, not points

## How It Works

1. Pick a lesson or game
2. The tutor creates an isolated practice workspace
3. You run real commands
4. The tutor evaluates the outcome (not the exact command)
5. If you get stuck, hints guide you from direction to solution
6. Progress persists across sessions

## Quick Start

```bash
npx @mcptoolshop/terminal-tutor doctor
npx @mcptoolshop/terminal-tutor tracks
npx @mcptoolshop/terminal-tutor next
```
